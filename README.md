# 师承 · 致那些陪我长大的动漫老师

一个致敬 80 后童年动漫老师的教师节单文件动画。

- 单文件 HTML，纯单机，无账号无联网
- 11 位老师的「墨色物件剪影」
- 移动端自适应（含触摸翻页）
- Web Audio 合成配乐，无外链

## 本地预览

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

或者直接双击 `index.html`。
